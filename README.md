## Лабораторная работа "Сверточные нейронные сети"

## Структура репозитория

- `lab10Lite.ipynb` – ноутбук для задания Lite: подготовка данных, изменение количества сегментирующих классов с 16 на 5, проведение 10 экспериментов с разными параметрами сверточной сети и визуализация результатов
- 
- `laba10Pro.ipynb` – ноутбук для задания Pro: подготовка данных, изменение количества сегментирующих классов с 16 на 7, доработка `simpleUnet` с учетом особенностей архитектуры U-Net
  
- `laba10Ultra_Pro.ipynb` – ноутбук для задания Ultra Pro: подготовка данных, изменение количества сегментирующих классов с 16 на 7 и реализация сегментации базы “Стройка” на основе модели PSPNet
  
- `Pytorchlab10Lite.ipynb` – ноутбук для задания Lite:сподготовка данных, изменение количества сегментирующих классов с 16 на 5, проведение 10 экспериментов с разными параметрами сверточной сети и визуализация результатов. Выполнено с использованием Pytorch

## Требования

Для запуска ноутбуков рекомендуется использовать **Google Colab**. Все необходимые библиотеки предустановлены в Colab.
